# /sc-qa — 公開前 QA チェック

エピソード JSON・シーン画像・ナレーションを精査し、**動画生成前 or 公開前** に問題を発見して修正する。

引数: `$ARGUMENTS` にエピソードID（例: `ep015`）

---

## STEP 0 — ファイル読み込み

```
EPISODE_ID = $ARGUMENTS（例: ep015）
EP_JSON    = episodes/{EPISODE_ID}.json
IMAGES_DIR = ~/Library/CloudStorage/GoogleDrive-naru.nakajima@gmail.com/マイドライブ/samurai-chronicles/{EPISODE_ID}/images/
```

1. `EP_JSON` を読み込む
2. `IMAGES_DIR` の画像ファイル一覧を取得（存在すれば）

---

## STEP 1 — ナレーション・テキスト QA

以下の観点で `scenes[*].narration`・`youtube_description`・`teaser_narration`・`shorts_narration` をすべてレビューする。

### 1-A. 歴史的事実チェック
- 年号・出来事・人物関係に明らかな誤りがないか
- 因果関係・時系列の矛盾がないか
- 主張の根拠が薄い/誇張されすぎている箇所はないか

### 1-B. 英語用語・ニュアンスチェック
よくある誤用パターンを必ず確認:
- 「dynasty」→ 天皇家以外への誤用（豊臣・徳川は **clan / regime / house** が適切）
- 「shogun」「emperor」「lord」の混同
- 固有名詞のローマ字表記ゆれ（Toyotomi / Hideyoshi 等）
- 「the most powerful / greatest / strongest」等の最上級の過度な多用

### 1-C. 英語文法・スペルチェック
- アポストロフィ抜け（Japan's / Tokugawa's 等）
- 動詞の時制ゆれ（過去形と現在形の混在）
- 冠詞の誤り（the / a）
- 明らかな typo

---

## STEP 2 — 画像プロンプト QA

`scenes[*].image_prompt` を全件レビュー。

### 2-A. 重複・類似チェック
- 同じまたは非常に似た構図・キーワードのプロンプトが複数ないか
- 特に `teaser` / `hook` / 終盤シーンで冒頭と同じ人物・場面が使われていないか
（例：幸村が冒頭にも終盤にも登場してしまうと "reveal" の演出が弱まる）

### 2-B. 歴史的視覚表現チェック
- 日本の武将・城・合戦の描写として不自然な指示がないか
  - ヨーロッパ風の城を指定していないか
  - 実在武将の象徴的な装備（家紋・兜・旗印）を明示しているか
    - 真田幸村 → 六文銭 / 鹿角兜
    - 徳川家康 → 葵紋
    - 豊臣秀吉 → 桐紋
  - テキスト・文字を画像内に描かせていないか（AI生成は文字が崩れる）

---

## STEP 3 — 画像×ナレーション 整合性チェック（画像がある場合）

`IMAGES_DIR` に `S01.png`〜`S{N}.png` が存在する場合、各シーンについて:

1. Read ツールで画像を読み込む（S01.png → scene_id=1 のナレーションと照合）
2. 以下を確認:
   - 画像の内容がナレーションの文脈と合っているか
   - 登場人物・時代・場所の視覚的ミスマッチがないか
   - AI 特有の不自然さ（崩れた文字、異様な手・顔、ヨーロッパ風建築）が目立つか
3. **問題あり** と判断した場合のみ報告（正常シーンは省略）

> 画像が多い場合は特に重要なシーン（S01・hook・キャラクター初登場・クライマックス・S19）を優先。

---

## STEP 4 — レポート出力

以下のフォーマットで出力する。問題がないカテゴリは「✅ 問題なし」と1行で済ませる。

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  QA REPORT — {EPISODE_ID}「{youtube_title}」
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【1. ナレーション / テキスト】
  [CRITICAL] シーン番号・箇所: 問題の説明 → 修正案
  [WARNING]  シーン番号・箇所: 問題の説明 → 修正案
  ✅ 文法・スペル: 問題なし

【2. 画像プロンプト】
  [WARNING] S05: ...
  ✅ 重複: 問題なし

【3. 画像×ナレーション 整合性】
  [WARNING] S07: ...
  ✅（画像未生成のためスキップ）

【修正優先度サマリー】
  CRITICAL x{N} — 公開前に必ず対応
  WARNING  x{N} — できれば対応
```

---

## STEP 5 — 修正の実施

レポートを表示した後、ユーザーに確認する:

```
上記 {CRITICAL数} 件の CRITICAL・{WARNING数} 件の WARNING が見つかりました。
修正を行いますか？
  [A] CRITICAL のみ修正（ep.json を直接編集）
  [B] CRITICAL + WARNING をすべて修正
  [C] 個別に選択
  [D] 修正なし（レポートのみ）
```

ユーザーが A / B / C を選んだ場合、`episodes/{EPISODE_ID}.json` を直接編集して修正を適用する。
修正後は変更箇所を箇条書きで報告する。
