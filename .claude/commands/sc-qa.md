# /sc-qa — 画像 × ナレーション 整合性チェック（単体実行用）

**主な用途:** 既存エピソードの遡り確認、または `/sc-new` フロー外で画像が生成された後の確認。

> `/sc-new` フロー内では STEP 5c として自動実行される。
> 歴史的事実・用語・文法・画像プロンプト重複は STEP 4（制作確認書）で確認済みのため、
> このコマンドは**画像生成後でしか確認できない項目のみ**をチェックする。

引数: `$ARGUMENTS` にエピソードID（例: `ep015`）

---

## STEP 1 — ファイル読み込み

```
EPISODE_ID = $ARGUMENTS（例: ep015）
EP_JSON    = episodes/{EPISODE_ID}.json
IMAGES_DIR = ~/Library/CloudStorage/GoogleDrive-naru.nakajima@gmail.com/マイドライブ/samurai-chronicles/{EPISODE_ID}/images/
```

`EP_JSON` を読み込む。`IMAGES_DIR` の画像ファイル一覧を確認する。

---

## STEP 2 — 画像 × ナレーション 整合性チェック

`IMAGES_DIR` の `S01.png`〜`S{N}.png` を Read ツールで読み込み、
各シーン画像をナレーション・image_prompt と照合する。

確認する観点:
- 画像の内容がナレーションの文脈と合っているか
- 登場人物・時代・場所の視覚的ミスマッチ（例: ヨーロッパ風の城、異なる武将の装備）
- AI 特有の不自然さで目立つもの（崩れた文字、異様な手・顔）
- 冒頭と終盤で同じキャラクターの同じ構図が被っていないか（reveal 演出の破綻）

**問題ありのシーンのみ報告**（正常シーンは省略）。
画像が多い場合は S01・hook・キャラクター初登場・クライマックス・S19 を優先。

画像が存在しない場合は「画像未生成のためスキップ」と報告して終了。

---

## STEP 3 — レポート出力・修正

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  画像 QA — {EPISODE_ID}「{youtube_title}」
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  [WARNING] S{N}: {問題の説明} → 対応案: {対応案}
  ✅ 主要シーン: 問題なし
  WARNING {N}件
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

WARNING がある場合はユーザーに確認：
```
[A] 画像を再生成して修正（zoom_anchor も再判定）
[B] 問題は許容してそのまま
```

問題がなければ「✅ 全シーン問題なし」と報告して終了。
